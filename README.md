## 🚀 Featured Projects

### 1. RUStudentAssist — RAG-Based Student Assistant
A retrieval-augmented generation application designed to help Rutgers Business School students find answers to university-related questions.

- Combines FAISS vector search and BM25 keyword retrieval for hybrid search.
- Uses a Streamlit interface for an accessible question-answering experience.
- Demonstrates practical applications of LLMs and information retrieval.

🔗 [Try RU Student Assistant](https://llmprojectgroup3.streamlit.app/)

### 2. InstaSecure — PPE Detection
A computer vision project using YOLOv8 to detect personal protective equipment (PPE), demonstrating object detection and AI-based safety monitoring.

### 3. TradoCompanion — B2B E-Commerce
A Django-based B2B e-commerce project that earned **Second Prize**.

- Demonstrates web application development and business-focused problem solving.

## 💻 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/ssaumz/Saumya-Poojari-Portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd Saumya-Poojari-Portfolio
   ```

3. Open `index.html` in your browser.

Since this is a static HTML portfolio, no build process or package installation is required.
